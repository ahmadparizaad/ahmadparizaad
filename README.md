## Typing Animation
```javascript
const typingEffect = () => {
  const text = 'Hello, I am Ahmad!';
  let index = 0;
  const interval = setInterval(() => {
    if (index < text.length) {
      process.stdout.write(text.charAt(index));
      index++;
    } else {
      clearInterval(interval);
    }
  }, 100);
};
typingEffect();
```
